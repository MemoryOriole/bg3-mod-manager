## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Load Order Control** | Drag and drop mods to set the exact load order Larian recommends |
| **Conflict Detection** | Automatically identifies mods that override the same game files |
| **Save Management** | Backup and restore save files before installing new mod configurations |
| **NexusMods Integration** | Browse and download mods directly from Nexus without leaving the app |
